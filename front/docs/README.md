# docs

화면 사용법, 이전 작업 메모, 캡처 이미지를 모아 둔 디렉터리입니다. 실행 중인 코드의 기준 설명은 각 소스 폴더의 `README.md`를 봅니다.

이 디렉터리 이름은 원래 `front/readme.md`였습니다. `front/README.md` 파일과 Windows에서 이름이 겹쳐 `docs`로 옮겼습니다. 캡처 파일은 이 폴더 안에 그대로 있습니다.

## 메모

| 파일 | 내용 |
| --- | --- |
| `strawberry-Docter_Django.md` | 화면 사용 순서와 템플릿 구조. 건강 점수 계산식 포함 |
| `strawberry-Docter_Django_Backend.md` | 비어 있음 |
| `strawberry-Docter_Django_DB-test.md` | 2026년 4월 MariaDB 연결 확인 기록. 당시 예시에 적혀 있던 DB 비밀번호는 저장소에 남기지 않도록 지웠습니다 |

`strawberry-Docter_Django.md`의 디렉터리 트리는 초기 Django 프로젝트 이름(`django-blog`) 기준입니다. 현재 화면 루트는 `front/`입니다.

## 캡처

`image.png`, `image-1.png` … `image-10.png`는 사용 안내 문서에서 참조하는 화면 캡처입니다. 문서 안의 이미지 문법은 Markdown 링크와 HTML이 섞여 있어 뷰어에 따라 이미지가 보이지 않을 수 있습니다. 파일은 이 폴더에 있습니다.
